# Product image credits

The ten sample-catalog images in this folder are composites: a plain
category-tinted background drawn for this project, with artwork from the
**Noto Emoji** project placed on it.

- Source: <https://github.com/googlefonts/noto-emoji> (`svg/` directory)

- Licence: **Apache License 2.0** — the project's README states that "Tools and
  most image resources are under the Apache license, version 2.0". (The SIL Open

Apache 2.0 permits use, modification and redistribution, including in this
project, provided the licence notice is retained — which is what this file does.
A copy of the licence is at <https://www.apache.org/licenses/LICENSE-2.0>.

| `coffee.webp` | hot beverage | U+2615 |
| `vacuum.webp` | broom | U+1F9F9 |

| `cleancode.webp` | closed book | U+1F4D5 |
| `ddia.webp` | blue book | U+1F4D8 |

These are stand-ins for a demo catalog, not photographs of real products. To use
your own photography instead, replace the `.webp` files here (keeping the
filenames) or point `image_url` at a different path — the templates read the
value straight from the database.
